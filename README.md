# 🎰 Python Casino Project

A command-line interface (CLI) casino simulation built with Python and Pygame. Experience the thrill of the casino directly from your terminal!

## 🎮 Games Included

- **Roulette**: Bet on your favorite numbers or colors.
- **Blackjack**: Try to reach 21 without going over.
- **Dice**: Test your luck with the roll of the dice.
- **Slot Machine**: Spin the reels for a chance to win big.
- **Party Mode**: Play Poker with friends in a local multiplayer setup.
- **Horse Racing**: (Coming soon!)

## 👥 Multiplayer (Party Mode)

If you want to play **Poker** with friends, follow these steps:

1.  Select **Party Mode** (Option 6) from the main menu.
2.  **Host**: One player must choose `host` to create the game lobby.
3.  **Join**: Other players must choose `join` and enter the host's IP address to connect.


## 🚀 Features

- **Starting Balance**: Begin your journey with $5,000.
- **Interactive Menu**: Easy-to-use navigation system.
- **Audio Effects**: Integrated sounds using `pygame.mixer` for an immersive experience.
- **Clean Interface**: Automatic console clearing for a better visual experience.

## 🛠️ Requirements

- Python 3.x
- `pygame` library (for sound effects)

To install the requirements:
```bash
pip install pygame
```

## 📦 How to Run

1. Clone the repository or download the files.
2. Ensure you are in the project root directory.
3. Run the main script:
   ```bash
   python main/main.py
   ```
